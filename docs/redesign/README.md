# Tennisimo redesign (design source)

HTML design artboards exported from the "Tennisimo Redesign" canvas. They are
reference mockups with sample data, not app code. Open the `.dc.html` files in
the design canvas; `canvas.json` holds their layout.

Screens: Home (`Main`), Swing results (`Session`), Matches and rallies tab
(`MatchesList`), match result (`Match`), load error (`MatchesError`), Profile,
Privacy, Delete account, and the dark Home (`Web`).

The Flutter implementation of the Matches / Rallies screens is
`frontend/lib/screens/matches_screen.dart`.
